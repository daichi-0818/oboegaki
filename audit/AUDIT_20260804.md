## Safety hardening in this revision

- `--manifest` is fully symlink-resolved (every existing component) before
  the workspace-containment decision; escapes — including via a symlink
  inside the workspace — fail before any write.
- `link` is two-phase: full preflight (dangerous targets `/`, `$HOME`,
  workspace root and their ancestors — including case-insensitive aliases
  via `samefile` for real paths; source/target overlap and samefile
  aliasing; nested and duplicate targets; backup directory overlapping
  any source/target; existing and planned backup collisions) rejects the
  entire run before a single write; every target is additionally checked
  against every entry's source (ancestor/descendant/samefile), and
  not-yet-created targets are deduplicated by an NFC+casefold portable
  key. Backup names are SHA-256 of the absolute target path
  (collision-resistant, plus preflight collision detection). Execution
  journals every mutation (moves, replaced-symlink original link text,
  created parent directories, created links) to
  `transaction_journal.json` and rolls all of it back on mid-failure;
  `restore_ledger.json` records full original/backup paths.
- Wiki links that resolve to more than one file fail as ambiguous.
- Orphan detection compares normalised relative paths, not basenames.
- Exact-duplicate detection pools across all opted-in memory roots.
